藍芽喇叭

5W USB 供電式迷你藍牙喇叭 DIY 完整設計與製作

這個專案的目標是自行製作一組體積小、可以直接透過 USB 供電、不需要內建電池，並且能透過手機、平板或電腦播放音樂的 5W 迷你藍牙喇叭。

我建議採用模組化設計：藍牙接收、音訊放大、USB 電源、喇叭單體及外殼分開處理。這樣不但容易組裝，也方便日後更換零件、升級音質或自行修改電路。

特別注意：5W 與 USB 5V 的關係

這是整個專案最重要的電路設計問題。

USB 5V 並不代表一定能直接得到 5W 的音訊輸出。

例如：

  • USB 5V × 1A = 5W 輸入功率。
  • USB 5V × 2A = 10W 輸入功率。
  • 放大器本身有功率損耗。
  • 喇叭輸出的音訊功率不可能大於輸入功率。

如果希望取得真正接近 5W RMS 的單聲道輸出，建議使用 USB 5V 2A 電源，再經過升壓電路提供放大器約 9V 電源。

這樣比較容易達到設計目標。

我的建議：採用 USB 5V → 9V 升壓 → D 類音訊放大器 → 4Ω 喇叭的架構。

1. USB 電源輸入

建議採用 USB-C 母座模組，輸入 5V。

建議規格：

  • 輸入電壓：5V。
  • 電源供應器：5V / 3A。
  • USB-C 母座：具有正確 CC 下拉電阻的電源模組。
  • 電源線：支援 3A 的 USB-C 線。

為什麼建議 3A？

雖然平均播放音樂時可能只需要 1～1.5A，但低音瞬間輸出會造成電流增加，供電不足容易發生破音、重啟或藍牙斷線。

將 USB 的 5V 升壓到 9V。

安裝時先不要接功放，使用萬用電表調整輸出至 9.0V，再進行後續組裝。

3. 音訊功率放大器

Buy TPA3110 30W digital power amplifier modules pack of 10pcs

建議採用 TPA3110D2 PBTL 單聲道模組。

它是 D 類放大器，具有較高效率，適合小型 USB 供電喇叭。

注意：

  • 電源必須符合所購模組的規格，建議工作電壓 9V。
  • 確認模組支援 PBTL 單聲道輸出。
  • 確認 4Ω 喇叭可用。
  • 不要只看商品標示的 30W，因為該數字通常是在更高電壓下測得。

4. Bluetooth 接收模組

建議選擇具有下列端子的音訊接收板：

  • VCC：5V。
  • GND：接地。
  • L：左聲道音訊輸出。
  • R：右聲道音訊輸出。
  • ANT：天線（視模組設計）。

不要購買只有 BLE 資料傳輸功能的普通藍牙模組，必須是支援 A2DP 音訊接收的模組。

5. 喇叭單體

建議使用：

  • 直徑：2～3 吋。
  • 阻抗：4Ω。
  • 額定功率：5W。
  • 類型：Full Range 全音域。

我會優先選擇 2～3 吋的全音域喇叭，而不是單純追求小直徑。喇叭單體的效率、振膜面積及箱體容積，都會影響實際音質。

四、實際接線方式

這裡要特別注意：TPA3110 的 PBTL 輸出是橋接式輸出，喇叭兩端都必須接功放的輸出端，不能把喇叭負極接到 GND。

1. 電源接線

USB-C 5V
   │
   ├── 5V ─────── Bluetooth VCC
   │
   ├── GND ────── Bluetooth GND
   │
   └── 升壓模組 IN+
          │
          └── 升壓模組 IN-

升壓模組 OUT+ (9V)
   │
   └──────────── 功放 VCC

升壓模組 OUT-
   │
   └──────────── 功放 GND

Bluetooth 與功放的訊號地必須共地。

2. Bluetooth 音訊接線

因為單聲道喇叭要同時播放左右聲道，不能直接把 L 和 R 短接在一起。

建議使用兩個 1kΩ 電阻：

Bluetooth L ─── 1kΩ ──┐
                       ├── MONO ── 音量控制 ── AMP IN
Bluetooth R ─── 1kΩ ──┘

Bluetooth GND ─────────────────── AMP GND

兩個電阻的作用是將左右聲道混合，避免左右輸出端直接互相驅動。

音量控制可以使用 10kΩ 電位器：

  • 一端接 MONO 訊號。
  • 另一端接 GND。
  • 中間端接功放音訊輸入。

3. 喇叭接線

TPA3110 PBTL

SPK+ ───────── 喇叭 +
SPK- ───────── 喇叭 -

重要安全事項

不要把 SPK- 接到電源 GND，也不要將 SPK+ 或 SPK- 接到其他音訊設備的接地端。這是 BTL/PBTL 功放常見的接線錯誤。

五、喇叭外殼設計

外殼是決定聲音品質的重要因素。即使使用相同的喇叭單體，不同的箱體容積及結構，也會產生很大的音質差異。

我建議第一版採用密閉式音箱（Sealed Enclosure），不需要設計導音管，容易製作，也比較不容易出現低音共振問題。

1. 外殼尺寸建議

如果選擇 2～3 吋喇叭，可以先用以下尺寸進行原型設計。

項目 初始建議
外殼寬度 130mm
外殼高度 110mm
外殼深度 120mm
板材厚度 6mm
內部結構 密閉式
喇叭位置 正面中央
電子電路 背面或底部

這組尺寸的內部容積約為 1.1 公升（扣除板材厚度後，尚未扣除喇叭及電路所占空間）。

注意：這只是方便製作的原型尺寸，不是所有 2～3 吋單體都適用的最佳箱體。正式製作前應依照喇叭的 Thiele-Small 參數（尤其是 Vas、Qts、Fs）確認容積。若使用 2 吋單體，可能需要更小的箱體。

2. 外殼製作方式

有三種選擇：

A. 木板製作

最推薦

  • 6～9mm 夾板或 MDF。
  • 木工膠黏合。
  • 內部接縫使用矽膠密封。
  • 容易修改及打磨。

B. 3D 列印

  • 使用 PETG 或 ABS。
  • 壁厚建議 3～4mm 起。
  • 可直接設計螺絲孔、電路固定座。
  • 適合精確控制外型。

C. 壓克力製作

  • 透明外觀。
  • 容易觀察內部電路。
  • 接合處必須做好密封。
  • 板材振動可能影響聲音。

3. 外殼內部處理

外殼內部建議：

  1. 內壁貼上薄型吸音材料。
  2. 後壁及側壁可使用聚酯纖維吸音棉。
  3. 不要堵住喇叭背面的通氣空間。
  4. 不要讓吸音材料碰觸振膜。
  5. 電路板固定在獨立位置，避免與喇叭振動接觸。
  6. 所有接縫保持密封。

第一版不需要被動輻射器（Passive Radiator），等測試後覺得低音不足，再考慮第二版修改。

六、實際製作步驟

我建議將整個工程分成七個階段，不要一開始就把所有零件焊接固定在外殼內。

  1. 階段一：零件檢查

    將所有電子零件準備好。

    使用萬用電表確認：

    • USB 輸出是否為 5V。
    • 升壓模組是否可以調整到 9V。
    • Bluetooth 模組是否支援 A2DP。
    • 功放板是否支援 4Ω 負載。
    • 喇叭阻抗及額定功率是否正確。 先不要接上喇叭。
    • USB 輸入電壓。
    • 升壓模組輸出電壓。
    • 輸出電壓是否穩定在 9V。 可以先接一個適當的假負載，確認升壓模組不會因負載而大幅降壓。

      階段二：測試 USB 供電

      將 USB-C 連接 5V / 3A 電源供應器。

      使用電表測量：

  3. 階段三：測試 Bluetooth

    單獨為 Bluetooth 模組供應 5V。

    使用手機搜尋藍牙裝置，完成配對。

    播放音樂，利用示波器或音訊測試設備確認 L、R 音訊輸出。

    如果沒有示波器，也可以先用已確認規格的音訊放大器進行低音量測試。

  4. 階段四：安裝音訊放大器

    先將左右聲道經過 1kΩ 電阻混音，再接至功放。

    接著：

    • 接上 9V 電源。
    • 確認 Bluetooth 與功放共地。
    • 確認功放沒有異常發熱。
    • 最後才接上 4Ω 喇叭。 初次測試時，音量旋鈕及手機音量都先調低。

  5. 階段五：測試聲音

    播放不同類型的音樂：

    • 人聲。
    • 古典音樂。
    • 爵士樂。
    • 低音測試音。
    • 左右聲道混合測試。 逐漸提高音量，觀察是否有破音、雜音或供電重啟。

    不要長時間使用滿功率正弦波測試，以免喇叭過熱。

  6. 階段六：製作外殼

    依照選定尺寸裁切板材。

    建議順序：

    1. 製作前面板並開喇叭孔。
    2. 製作左右側板。
    3. 製作頂板及底板。
    4. 製作背板。
    5. 黏合箱體。
    6. 完成內部密封。
    7. 安裝喇叭及保護網。
    8. 安裝 USB-C 插座、開關及音量旋鈕。

  7. 階段七：最終組裝

    將電路板固定在箱體內部。

    電源線、音訊線分開整理，喇叭線固定牢靠。

    完成後連接 USB-C 電源，使用手機配對，連續播放音樂至少 1～2 小時，檢查：

    • 電源穩定度。
    • 藍牙連線穩定度。
    • 功放溫度。
    • 外殼是否有異常共振。
    • 音量與音質是否符合預期。

七、電路配置與安全注意事項

1. 電源保護

建議 USB 輸入端增加：

  • 適當額定值的自復式保險絲或保險絲。
  • 反接保護（如果電源模組有外露接線）。
  • 輸入濾波電容。
  • 升壓模組輸出端的適當濾波電容。

電容值依升壓及功放模組廠商建議配置，不要任意增加到超出模組承受範圍。

2. 電源與音訊分流

Bluetooth 模組使用 5V，功放使用 9V。

                  USB-C 5V
                     │
             ┌───────┴────────┐
             │                │
          Bluetooth       升壓模組
             │                │
           5V/GND             9V
             │                │
             │             功率放大器
             │                │
             └── 音訊訊號 ────┘
                              │
                            喇叭

升壓模組與功放會產生開關電流及電磁干擾，因此：

  • Bluetooth 天線遠離升壓電感。
  • 音訊輸入線盡量短。
  • 電源線與音訊線不要長距離平行。
  • 必要時在 Bluetooth 模組 5V 端增加適當的濾波。

3. 功率與電流估算

假設喇叭輸出 5W，功放效率約 90%，升壓效率約 90%。

\[ P_{USB}=\frac{5}{0.9\times0.9} \approx6.17W \]

所以：

\[ I_{USB}=\frac{6.17}{5} \approx1.23A \]

這是理想的滿功率連續輸出估算，還沒有計入 Bluetooth、其他電路消耗及瞬間電流需求。

因此，選擇 5V / 3A 電源比較合理。

補充：5W 是設計目標，不是保證值。 實際可達到的乾淨 RMS 輸出，要看功放供電、負載、失真率及模組實測結果。

  4. 前級、DAC、藍牙接收器與功率放大器如何整合。
  5. 如何設計自己的 PCB、機箱、音量控制及保護電路。
  6. 如何測量失真、頻率響應、信噪比及實際輸出功率。

在此將以 USB 供電 5W 藍牙喇叭作為入門基礎，再延伸到 20W、50W、100W 甚至更高功率的桌上型音響。

一、現代音響擴大機的主要種類

目前常見的音響擴大機可以分成五種。

1. Class A：甲類擴大機

BuildAudioAmps

Class A 是較傳統的高線性放大方式。

其基本特點是：

  • 輸出晶體管在整個訊號週期持續導通。
  • 電路設計相對容易理解。
  • 可以達到很低的交越失真。
  • 靜態耗電量高。
  • 發熱量大。
  • 散熱器通常需要很大的體積。

典型效率理論上最高約 25%（電阻負載、單端形式），某些變壓器耦合設計可更高。

適合：

  • 低功率耳機擴大機。
  • 特定高音質單端放大器。
  • 電子電路教學與實驗。

不適合以 USB 5V 供電的高功率喇叭。

2. Class AB：乙類與甲乙類擴大機

High-Power Dual-Channel Amplifier Board (2SA1943/2SC5200 Original Toshiba Tube)

Class AB 是傳統 Hi-Fi 音響非常常見的設計。

主要利用互補功率晶體管放大正、負半週訊號。

優點：

  • 音質成熟。
  • 電路設計資料豐富。
  • 線性度良好。
  • 適合中高功率輸出。
  • 不需要像 Class A 一樣持續消耗大量靜態功率。

缺點：

  • 效率低於 Class D。
  • 散熱器體積較大。
  • 電源供應器通常較重。
  • 偏壓調整與熱補償需要注意。

一般可以用在 20W～200W 的 DIY 家用音響。

3. Class D：數位式開關功率放大器

TPA3255: TPA3255ampBoard-question

最推薦 DIY 入門與現代音響

Class D 是目前非常值得學習的音響放大技術。

它不是單純將類比訊號轉換成數位音訊，而是使用高速開關方式控制功率輸出。

基本原理：

  1. 輸入音訊。
  2. 透過調變電路形成 PWM 或其他開關控制訊號。
  3. 功率 MOSFET 高速切換。
  4. 經過 LC 低通濾波器。
  5. 還原成供應喇叭的音訊。

Principe classe D

主要優點：

  • 效率高，常見設計可達 85%～95% 左右。
  • 體積小。
  • 發熱量低於同功率 Class AB。
  • 容易實現 50W、100W 甚至更高功率。
  • 適合 USB-C PD、DC 電源及開關式電源。

需要注意：Class D 不代表一定是數位音訊。它也可以直接放大類比音訊輸入。

4. Class G / Class H

這兩類設計透過切換或追蹤不同電源電壓，減少功率級的耗散。

特點：

  • 比傳統 Class AB 更有效率。
  • 電路設計較複雜。
  • 電源軌控制及切換設計需要仔細處理。

適合進階音響設計，但如果目標是小型 DIY 音響，我會優先選擇 Class D。

特別注意：為什麼商品標示的瓦數不能直接相信？

假設某個網路商品寫著：

TPA3116D2 100W + 100W

並不代表使用 12V 電源就能輸出 200W。

輸出功率與供電電壓、喇叭阻抗、電路形式及失真率有直接關係。

最基本的功率公式：

\[ P=\frac{V_{\mathrm{RMS}}^2}{R} \]

其中：

  • P：輸出功率。
  • V：喇叭兩端的 RMS 電壓。
  • R：喇叭負載阻抗。

例如，4Ω 喇叭要輸出 50W：

\[ V_{\mathrm{RMS}}=\sqrt{50\times4} =14.14V \]

這表示喇叭兩端必須有約 14.14V RMS 的交流音訊電壓。

因此，必須考慮擴大機的供電電壓和輸出拓撲，不能只看晶片名稱。

七、如何自己設計 Class D 擴大機電路？

如果不滿足於購買現成模組，而希望自己設計 PCB，就要理解功率放大器內部的幾個重要電路。

1. Class D 的基本電路結構

Multilevel Class D Audio Amplifiers for Compact Consumer Applications

主要包含：

  1. 音訊輸入緩衝。
  2. PWM 調變器或整合式控制器。
  3. MOSFET Gate Driver。
  4. 半橋或全橋功率輸出。
  5. LC 濾波器（依架構而定）。
  6. 回授與保護電路。

對於初次設計，我不建議直接自行設計 MOSFET 開關級，因為高頻開關、死區時間、PCB 寄生電感及 EMI 都會大幅增加難度。

更好的做法是：

  • 使用 TI 原廠參考電路。
  • 使用成熟的功放 IC。
  • 自行設計周邊電源、前級及音訊介面。
  • 最後才嘗試重新設計功率級 PCB。

2. 電源去耦電容

這是 Class D 電路穩定性的關鍵。

通常需要：

  • 功率級附近的低 ESR 電解電容。
  • 陶瓷電容。
  • 依資料表要求配置的高頻去耦。
  • 適當的電源走線寬度。

電容必須盡量靠近晶片的電源端，不能將大電容放在遠離功放 IC 的位置，就認為已經完成去耦設計。

4. BTL 輸出注意事項

現代 Class D 很多都採用 BTL（Bridge-Tied Load）。

這表示：

OUT+ ─────── 喇叭 ─────── OUT-

喇叭兩端都由放大器驅動。

因此：

  • OUT- 不是 GND。
  • 不能把 OUT- 接到機殼地。
  • 不能將兩個 BTL 聲道的負端互相連接。
  • 不能直接使用共地式耳機或測試設備接到喇叭輸出端。

這是製作雙聲道 Class D 時非常重要的安全規則。

一套完整的 DIY 音響不應只有放大器，還應考慮保護喇叭及電路本身。

喇叭直流保護

如果功放發生故障，喇叭輸出端可能出現不正常的直流電壓，導致喇叭音圈過熱。

因此，傳統 Class AB 功放常使用 DC 偵測及喇叭繼電器保護。

Class D 則必須注意輸出拓撲：BTL 輸出不能使用一般共地式直流偵測電路直接測量其中一端。應使用適合差動輸出的偵測方式，或採用功放 IC 已提供的故障訊號。

THD+N 是判斷擴大器音質的重要數據。

簡單說：

  • 越低通常越好。
  • 必須同時記錄輸出功率及測試頻率。
  • 不能只比較不同廠商各自挑選的最佳數字。

20W 輸出 0.1%

這只是說明測試表格的示意數據，不代表某一款實際晶片的測量結果。

一般人耳可聽範圍約為 20Hz～20kHz。

測試時可以使用：

  • 20Hz。
  • 50Hz。
  • 100Hz。
  • 500Hz。
  • 1kHz。
  • 5kHz。
  • 10kHz。
  • 20kHz。

觀察輸出是否平坦，以及低頻、高頻是否有異常衰減。

這點特別重要。

七、如何判斷擴大機與喇叭是否匹配？

這是購買前一定要了解的技術問題。

1. 阻抗匹配

擴大機通常支援 4Ω、6Ω 或 8Ω 負載。

喇叭阻抗 購買建議
4Ω 確認擴大機支援 4Ω
6Ω 確認擴大機支援 6Ω 或相容負載
8Ω 通常較容易搭配

不要把兩顆 4Ω 喇叭並聯到同一個聲道，因為等效阻抗會變成 2Ω，可能超出功放能力。

2. 喇叭靈敏度

靈敏度通常用 dB SPL / 1W / 1m 表示。

假設：

  • 喇叭 A：86dB。
  • 喇叭 B：89dB。

在相同輸入功率及距離下，B 理論上可以高出約 3dB。

3dB 的差異相當於功率增加一倍。

因此，對於小型 D 類擴大機，選擇靈敏度較高的喇叭通常有利。

3. 如何計算所需功率？

可以用下列公式估算：

\[ SPL=S+10\log_{10}(P) \]

其中：

  • SPL：預估音壓。
  • S：喇叭靈敏度。
  • P：輸入功率（W）。

假設使用 88dB 靈敏度的喇叭：

輸入功率 理想估算音壓
1W 88dB
2W 91dB
5W 95dB
10W 98dB
20W 101dB
50W 105dB

這是假設在 1m、自由場、單支喇叭且不考慮壓縮及失真的估算。實際房間及立體聲聆聽會有所不同。

所以一般書房音響不一定需要 100W。

六、購買前必須注意的事項

1. 電源供應器不要忽略

D 類擴大機的實際輸出功率，很大程度取決於電源供應器。

例如：

  • O-NOORUS A80：使用原廠規格的 24V / 6.5A 電源。
  • O-NOORUS D3：常見配置為 36V / 5A。
  • AIYIMA A80：依照使用的 24–48V 電源版本而定。
  • Fosi ZA3：48V / 5A 版本比 32V / 5A 版本有更大的輸出餘裕。

不要因為接頭相同，就把不同擴大機的電源互換。必須確認電壓、電流、極性、接頭規格及原廠限制。

2. 喇叭阻抗不要只看標示的 8Ω

例如 Diamond 12.1 標示 8Ω 相容，但最低阻抗為 4Ω。這表示擴大機實際上仍可能需要承受 4Ω 負載。

所以不能只看到「8Ω」就認為一定很好推；也要看最低阻抗及阻抗曲線。

3. 喇叭線與擺放也會影響結果

  • 喇叭線使用一般品質良好的 OFC 銅線即可，不需要一開始就買昂貴線材。
  • 5 吋喇叭可以先使用 14–16 AWG 喇叭線。
  • 喇叭高音單體盡量與耳朵同高。
  • 左右喇叭與聆聽位置形成近似等邊三角形。
  • 後方反射孔不要緊貼牆壁。
  • 兩支喇叭要保持相同的正負極接線。
