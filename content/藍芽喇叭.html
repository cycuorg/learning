5W USB 供電式迷你藍牙喇叭 DIY 完整設計與製作

這個專案的目標是自行製作一組體積小、可以直接透過 USB 供電、不需要內建電池，並且能透過手機、平板或電腦播放音樂的 5W 迷你藍牙喇叭。

我建議採用模組化設計：藍牙接收、音訊放大、USB 電源、喇叭單體及外殼分開處理。這樣不但容易組裝，也方便日後更換零件、升級音質或自行修改電路。

特別注意：5W 與 USB 5V 的關係

這是整個專案最重要的電路設計問題。

USB 5V 並不代表一定能直接得到 5W 的音訊輸出。

例如：

  • USB 5V × 1A = 5W 輸入功率。
  • USB 5V × 2A = 10W 輸入功率。
  • 放大器本身有功率損耗。
  • 喇叭輸出的音訊功率不可能大於輸入功率。

如果希望取得真正接近 5W RMS 的單聲道輸出，建議使用 USB 5V 2A 電源，再經過升壓電路提供放大器約 9V 電源。

這樣比較容易達到設計目標。

我的建議：採用 USB 5V → 9V 升壓 → D 類音訊放大器 → 4Ω 喇叭的架構。

二、系統電路架構

整體可以分成五個部分：

USB-C 5V / 3A 電源輸入

DC-DC 升壓模組

5V → 9V

D 類音訊功率放大器

TPA3110 單聲道 PBTL 模組

4Ω / 5W 全音域喇叭

Bluetooth 5.x 接收模組

手機音訊 → 左右聲道混合 → 功放輸入

音訊訊號

Bluetooth 接收模組的音訊輸出接至功率放大器輸入；與上述電源路徑分開。

1. USB 電源輸入

建議採用 USB-C 母座模組，輸入 5V。

建議規格：

  • 輸入電壓：5V。
  • 電源供應器：5V / 3A。
  • USB-C 母座：具有正確 CC 下拉電阻的電源模組。
  • 電源線：支援 3A 的 USB-C 線。

為什麼建議 3A？

雖然平均播放音樂時可能只需要 1～1.5A，但低音瞬間輸出會造成電流增加，供電不足容易發生破音、重啟或藍牙斷線。

2. DC-DC 升壓模組

將 USB 的 5V 升壓到 9V。

選購時建議：

項目 規格
輸入 5V
輸出 9V
連續輸出能力 建議至少 10W，最好有 15～20W 餘裕
輸出電流 依模組散熱及實際規格確認
保護 過流、過溫較佳

可以參考：

  • MT3608 Voltage Boost Converter – DC-to-DC Step Up Module：MT3608 升壓模組。
  • [環島科技]MT3608 DC-DC升壓模塊2A升壓板輸入電壓2-24V升5/9/12/-28V可調：可調式升壓模組。

重要：MT3608 雖然便宜，但不建議直接當成這個 5W 專案的主要升壓電源。 它的實際連續輸出能力受輸入電壓、電感、二極體及散熱限制。應選用有明確連續功率規格的升壓模組。

安裝時先不要接功放，使用萬用電表調整輸出至 9.0V，再進行後續組裝。

3. 音訊功率放大器

Buy TPA3110 30W digital power amplifier modules pack of 10pcs

建議採用 TPA3110D2 PBTL 單聲道模組。

它是 D 類放大器，具有較高效率，適合小型 USB 供電喇叭。

注意：

  • 電源必須符合所購模組的規格，建議工作電壓 9V。
  • 確認模組支援 PBTL 單聲道輸出。
  • 確認 4Ω 喇叭可用。
  • 不要只看商品標示的 30W，因為該數字通常是在更高電壓下測得。

TPA3110 的模組資料可參考 TPA3110 模組規格。

4. Bluetooth 接收模組

建議選擇具有下列端子的音訊接收板：

  • VCC：5V。
  • GND：接地。
  • L：左聲道音訊輸出。
  • R：右聲道音訊輸出。
  • ANT：天線（視模組設計）。

不要購買只有 BLE 資料傳輸功能的普通藍牙模組，必須是支援 A2DP 音訊接收的模組。

5. 喇叭單體

建議使用：

  • 直徑：2～3 吋。
  • 阻抗：4Ω。
  • 額定功率：5W。
  • 類型：Full Range 全音域。

我會優先選擇 2～3 吋的全音域喇叭，而不是單純追求小直徑。喇叭單體的效率、振膜面積及箱體容積，都會影響實際音質。

四、實際接線方式

這裡要特別注意：TPA3110 的 PBTL 輸出是橋接式輸出，喇叭兩端都必須接功放的輸出端，不能把喇叭負極接到 GND。

1. 電源接線

USB-C 5V
   │
   ├── 5V ─────── Bluetooth VCC
   │
   ├── GND ────── Bluetooth GND
   │
   └── 升壓模組 IN+
          │
          └── 升壓模組 IN-

升壓模組 OUT+ (9V)
   │
   └──────────── 功放 VCC

升壓模組 OUT-
   │
   └──────────── 功放 GND

Bluetooth 與功放的訊號地必須共地。

2. Bluetooth 音訊接線

因為單聲道喇叭要同時播放左右聲道，不能直接把 L 和 R 短接在一起。

建議使用兩個 1kΩ 電阻：

Bluetooth L ─── 1kΩ ──┐
                       ├── MONO ── 音量控制 ── AMP IN
Bluetooth R ─── 1kΩ ──┘

Bluetooth GND ─────────────────── AMP GND

兩個電阻的作用是將左右聲道混合，避免左右輸出端直接互相驅動。

音量控制可以使用 10kΩ 電位器：

  • 一端接 MONO 訊號。
  • 另一端接 GND。
  • 中間端接功放音訊輸入。

3. 喇叭接線

TPA3110 PBTL

SPK+ ───────── 喇叭 +
SPK- ───────── 喇叭 -

重要安全事項

不要把 SPK- 接到電源 GND，也不要將 SPK+ 或 SPK- 接到其他音訊設備的接地端。這是 BTL/PBTL 功放常見的接線錯誤。

五、喇叭外殼設計

外殼是決定聲音品質的重要因素。即使使用相同的喇叭單體，不同的箱體容積及結構，也會產生很大的音質差異。

我建議第一版採用密閉式音箱（Sealed Enclosure），不需要設計導音管，容易製作，也比較不容易出現低音共振問題。

1. 外殼尺寸建議

如果選擇 2～3 吋喇叭，可以先用以下尺寸進行原型設計。

項目 初始建議
外殼寬度 130mm
外殼高度 110mm
外殼深度 120mm
板材厚度 6mm
內部結構 密閉式
喇叭位置 正面中央
電子電路 背面或底部

這組尺寸的內部容積約為 1.1 公升（扣除板材厚度後，尚未扣除喇叭及電路所占空間）。

注意：這只是方便製作的原型尺寸，不是所有 2～3 吋單體都適用的最佳箱體。正式製作前應依照喇叭的 Thiele-Small 參數（尤其是 Vas、Qts、Fs）確認容積。若使用 2 吋單體，可能需要更小的箱體。

2. 外殼製作方式

有三種選擇：

A. 木板製作

最推薦

  • 6～9mm 夾板或 MDF。
  • 木工膠黏合。
  • 內部接縫使用矽膠密封。
  • 容易修改及打磨。

B. 3D 列印

  • 使用 PETG 或 ABS。
  • 壁厚建議 3～4mm 起。
  • 可直接設計螺絲孔、電路固定座。
  • 適合精確控制外型。

C. 壓克力製作

  • 透明外觀。
  • 容易觀察內部電路。
  • 接合處必須做好密封。
  • 板材振動可能影響聲音。

3. 外殼內部處理

外殼內部建議：

  1. 內壁貼上薄型吸音材料。
  2. 後壁及側壁可使用聚酯纖維吸音棉。
  3. 不要堵住喇叭背面的通氣空間。
  4. 不要讓吸音材料碰觸振膜。
  5. 電路板固定在獨立位置，避免與喇叭振動接觸。
  6. 所有接縫保持密封。

第一版不需要被動輻射器（Passive Radiator），等測試後覺得低音不足，再考慮第二版修改。

六、實際製作步驟

我建議將整個工程分成七個階段，不要一開始就把所有零件焊接固定在外殼內。

  1. 階段一：零件檢查

    將所有電子零件準備好。

    使用萬用電表確認：

    • USB 輸出是否為 5V。
    • 升壓模組是否可以調整到 9V。
    • Bluetooth 模組是否支援 A2DP。
    • 功放板是否支援 4Ω 負載。
    • 喇叭阻抗及額定功率是否正確。 先不要接上喇叭。
    • USB 輸入電壓。
    • 升壓模組輸出電壓。
    • 輸出電壓是否穩定在 9V。 可以先接一個適當的假負載，確認升壓模組不會因負載而大幅降壓。

      階段二：測試 USB 供電

      將 USB-C 連接 5V / 3A 電源供應器。

      使用電表測量：

  3. 階段三：測試 Bluetooth

    單獨為 Bluetooth 模組供應 5V。

    使用手機搜尋藍牙裝置，完成配對。

    播放音樂，利用示波器或音訊測試設備確認 L、R 音訊輸出。

    如果沒有示波器，也可以先用已確認規格的音訊放大器進行低音量測試。

  4. 階段四：安裝音訊放大器

    先將左右聲道經過 1kΩ 電阻混音，再接至功放。

    接著：

    • 接上 9V 電源。
    • 確認 Bluetooth 與功放共地。
    • 確認功放沒有異常發熱。
    • 最後才接上 4Ω 喇叭。 初次測試時，音量旋鈕及手機音量都先調低。

  5. 階段五：測試聲音

    播放不同類型的音樂：

    • 人聲。
    • 古典音樂。
    • 爵士樂。
    • 低音測試音。
    • 左右聲道混合測試。 逐漸提高音量，觀察是否有破音、雜音或供電重啟。

    不要長時間使用滿功率正弦波測試，以免喇叭過熱。

  6. 階段六：製作外殼

    依照選定尺寸裁切板材。

    建議順序：

    1. 製作前面板並開喇叭孔。
    2. 製作左右側板。
    3. 製作頂板及底板。
    4. 製作背板。
    5. 黏合箱體。
    6. 完成內部密封。
    7. 安裝喇叭及保護網。
    8. 安裝 USB-C 插座、開關及音量旋鈕。

  7. 階段七：最終組裝

    將電路板固定在箱體內部。

    電源線、音訊線分開整理，喇叭線固定牢靠。

    完成後連接 USB-C 電源，使用手機配對，連續播放音樂至少 1～2 小時，檢查：

    • 電源穩定度。
    • 藍牙連線穩定度。
    • 功放溫度。
    • 外殼是否有異常共振。
    • 音量與音質是否符合預期。

七、電路配置與安全注意事項

1. 電源保護

建議 USB 輸入端增加：

  • 適當額定值的自復式保險絲或保險絲。
  • 反接保護（如果電源模組有外露接線）。
  • 輸入濾波電容。
  • 升壓模組輸出端的適當濾波電容。

電容值依升壓及功放模組廠商建議配置，不要任意增加到超出模組承受範圍。

2. 電源與音訊分流

Bluetooth 模組使用 5V，功放使用 9V。

                  USB-C 5V
                     │
             ┌───────┴────────┐
             │                │
          Bluetooth       升壓模組
             │                │
           5V/GND             9V
             │                │
             │             功率放大器
             │                │
             └── 音訊訊號 ────┘
                              │
                            喇叭

升壓模組與功放會產生開關電流及電磁干擾，因此：

  • Bluetooth 天線遠離升壓電感。
  • 音訊輸入線盡量短。
  • 電源線與音訊線不要長距離平行。
  • 必要時在 Bluetooth 模組 5V 端增加適當的濾波。

3. 功率與電流估算

假設喇叭輸出 5W，功放效率約 90%，升壓效率約 90%。

\[ P_{USB}=\frac{5}{0.9\times0.9} \approx6.17W \]

所以：

\[ I_{USB}=\frac{6.17}{5} \approx1.23A \]

這是理想的滿功率連續輸出估算，還沒有計入 Bluetooth、其他電路消耗及瞬間電流需求。

因此，選擇 5V / 3A 電源比較合理。

補充：5W 是設計目標，不是保證值。 實際可達到的乾淨 RMS 輸出，要看功放供電、負載、失真率及模組實測結果。
