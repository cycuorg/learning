學習 Rust 程式語言，建議採取「免費 PDF 教材＋實際寫程式＋練習題」的方式。

Rust 是一門值得學習的現代程式語言，特色包括：

  • 記憶體安全： 不需要傳統垃圾回收器，也能有效避免許多記憶體錯誤。
  • 執行效率高： 編譯成原生程式，效能接近 C、C++。
  • 適合系統開發： 可用於作業系統、網路服務、命令列工具及嵌入式開發。
  • 跨平台： 支援 Windows、Linux、macOS 等平台。

建議：不要一開始就讀太多進階技術，先學會 Rust 的基本語法，再深入了解它最重要的特色——Ownership（所有權）、Borrowing（借用）及 Lifetime（生命週期）。

二、學 Rust 應該從哪裡開始？

我建議分成六個階段。

Rust 初學者學習路線

  1. 第一階段：認識 Rust 預計 3～5 天
    • Rust 是什麼？
    • 安裝 Rust 編譯器。
    • 安裝 VS Code。
    • 學會 Cargo 專案管理。
    • 寫出第一個 Hello World。
  2. 第二階段：基本語法 預計 1～2 週
    • 變數 let、mut。
    • 數字、字串、布林型態。
    • if、loop、while、for。
    • 函式。
    • 陣列及 Vector。
  3. 第三階段：Rust 核心觀念 最重要預計 2～3 週
    • Ownership（所有權）。
    • Borrowing（借用）。
    • References（參照）。
    • Lifetime（生命週期）。
    • Stack 與 Heap。
  4. 第四階段：資料結構與錯誤處理 預計 1～2 週
    • Struct。
    • Enum。
    • Match。
    • Option。
    • Result。
    • Error Handling。
  5. 第五階段：進階程式設計 預計 2～4 週
    • Generic。
    • Trait。
    • Iterator。
    • Closure。
    • Module。
    • Crate。
  6. 第六階段：實際專案 持續練習
    • 命令列工具。
    • 檔案讀寫。
    • JSON 資料處理。
    • 網路 API。
    • 資料庫應用。
    • Web 後端服務。

如果每天可以花1～2小時，先用2～3個月建立基本能力，是相當合理的學習目標。

四、第一個 Rust 程式

建立專案：

bash

cargo new hello_rust
cd hello_rust

打開 src/main.rs，輸入：

rust

fn main() {
    println!("Hello, Rust!");

    let name = "Rust 學習者";

    println!("歡迎你，{}！", name);
}

執行：

bash

cargo run

輸出：

text

Hello, Rust!
歡迎你，Rust 學習者！

這就是你的第一個 Rust 程式。
