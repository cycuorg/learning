首先要釐清一個容易混淆的地方：O-NOORUS A80 與 AIYIMA A80 是兩台不同的擴大機。兩者都叫 A80，但使用的擴大晶片、輸入介面、輸出功率與產品定位都不同。

如果你指的是 O-NOORUS A80（Infineon MA12070），它是一台體積很小、具備 USB-C、藍牙、RCA、超低音輸出的 D 類綜合擴大機；如果你指的是 AIYIMA A80（TI TPA3255），則是功率與數位輸入規格更高、功能更完整的另一個級別。以下會以 O-NOORUS A80 為主角，並把兩者分開比較，避免買錯。

一、O-NOORUS A80：小體積、功能完整的入門 Hi-Fi 擴大機

2. 各項功能的實際用途

（1）MA12070 D 類放大晶片

MA12070 是 Infineon 的高效率 D 類放大平台。它的優勢是體積小、發熱相對低、適合桌面及小型家用音響。

與常見的 TPA3116D2 相比，A80 的定位更偏向整合式小型 Hi-Fi，而不是單純追求大功率。

要特別注意：產品標示的 2 × 80W 並不等於可以長時間連續輸出 160W。它使用 24V、6.5A 電源，輸入電力上限約為 156W，還要扣除放大器損耗。因此選購時，應把 80W 視為廠商標示的輸出能力，而不是保證的連續輸出功率。

（2）USB-C 數位輸入

這是 O-NOORUS A80 很值得注意的功能。

可以直接連接：

  • Windows 桌上型電腦
  • Windows 筆記型電腦
  • 支援 USB Audio 的平板或手機
  • 其他相容 USB 音訊輸出的裝置

相較於只使用藍牙，USB-C 有線連接通常更適合固定桌面音響，避免藍牙編碼及無線傳輸造成的限制。

（3）Bluetooth 無線輸入

QCC3034 藍牙接收晶片可支援 aptX、aptX HD 等傳輸格式，適合手機、平板及筆記型電腦無線播放。

實際能使用哪一種編碼，還取決於手機或電腦端是否支援。

（4）超低音輸出

A80 提供 RCA 超低音輸出，可以連接主動式 Subwoofer，組成 2.1 系統：

電腦／手機／CD 播放器

O-NOORUS A80

左、右被動喇叭

Stereo L/R

主動式超低音

RCA Sub Out

這個功能適合希望增加電影、電子音樂及低頻效果的使用者。不過購買前要確認超低音輸出是否具有固定低通濾波，以及分頻點能否調整；不能直接假設它有完整 DSP 分頻管理。

（5）RCA 立體聲輸出

這個輸出可以把 A80 當作前級訊號來源，連接另一台後級擴大機或其他音響設備。實際使用時，應確認輸出音量是否隨主音量控制，以免後級輸入過載。

**我的看法：**如果主要用途是電腦、書房、小客廳，搭配一對 5 吋或 6.5 吋書架喇叭，O-NOORUS A80 是很有吸引力的入門整合方案。

2. 如何選擇？

  • 希望簡單、便宜、小體積：O-NOORUS A80。
  • 希望保留 O-NOORUS 的操作方式，但增加功率：O-NOORUS D3。
  • 希望 USB DAC、光纖、同軸、藍牙整合在一起：AIYIMA A80。
  • 已經有 DAC 或串流前級：Fosi ZA3。
  • 主要用手機藍牙播放：Fosi BT20A Max。
  • 希望以電腦作為主要數位訊源：AIYIMA A80 或 O-NOORUS D3。

這裡有個重要觀念：擴大機晶片較高階，不代表實際聽感一定較好。電源供應器、輸出濾波器、回授設計、PCB 佈局、保護電路及喇叭搭配，都會影響最終表現。

三、適合搭配的書架喇叭系列

選喇叭時，我建議先看四項：

  1. 阻抗：O-NOORUS A80 的規格以 4–8Ω 喇叭為主，不建議任意搭配低於 4Ω 的負載。
  2. 靈敏度：約 86–90dB 的喇叭都值得考慮；靈敏度越高，通常越容易在較小功率下得到足夠音量。
  3. 低音單體尺寸：4 吋適合桌面，5 吋適合小房間，6.5 吋較適合中型空間。
  4. 房間大小：房間越大、聆聽距離越遠，就越需要較高的功率餘裕及較大的喇叭。

六、購買前必須注意的事項

1. 電源供應器不要忽略

D 類擴大機的實際輸出功率，很大程度取決於電源供應器。

例如：

  • O-NOORUS A80：使用原廠規格的 24V / 6.5A 電源。
  • O-NOORUS D3：常見配置為 36V / 5A。
  • AIYIMA A80：依照使用的 24–48V 電源版本而定。
  • Fosi ZA3：48V / 5A 版本比 32V / 5A 版本有更大的輸出餘裕。

不要因為接頭相同，就把不同擴大機的電源互換。必須確認電壓、電流、極性、接頭規格及原廠限制。

2. 喇叭阻抗不要只看標示的 8Ω

例如 Diamond 12.1 標示 8Ω 相容，但最低阻抗為 4Ω。這表示擴大機實際上仍可能需要承受 4Ω 負載。

所以不能只看到「8Ω」就認為一定很好推；也要看最低阻抗及阻抗曲線。

3. 喇叭線與擺放也會影響結果

  • 喇叭線使用一般品質良好的 OFC 銅線即可，不需要一開始就買昂貴線材。
  • 5 吋喇叭可以先使用 14–16 AWG 喇叭線。
  • 喇叭高音單體盡量與耳朵同高。
  • 左右喇叭與聆聽位置形成近似等邊三角形。
  • 後方反射孔不要緊貼牆壁。
  • 兩支喇叭要保持相同的正負極接線。
