現代音響擴大機的選擇與 DIY 設計：從電路原理到完整音響系統

現代音響擴大機（Audio Amplifier）與傳統音響最大的差異，在於現在已經可以利用體積很小、效率很高的數位 D 類（Class D）放大器，製作出具有相當高輸出功率、低失真及良好音質的音響系統。

如果希望自己設計、組裝一套音響，我建議不要只從「幾瓦」開始選擇，而是先了解：

  1. 擴大機有哪些種類，各自的工作原理。
  2. 如何依照喇叭阻抗與功率選擇擴大機。
  3. 電源供應器如何決定擴大機的實際輸出能力。
  4. 前級、DAC、藍牙接收器與功率放大器如何整合。
  5. 如何設計自己的 PCB、機箱、音量控制及保護電路。
  6. 如何測量失真、頻率響應、信噪比及實際輸出功率。

在此將以 USB 供電 5W 藍牙喇叭作為入門基礎，再延伸到 20W、50W、100W 甚至更高功率的桌上型音響。

一、現代音響擴大機的主要種類

目前常見的音響擴大機可以分成五種。

1. Class A：甲類擴大機

BuildAudioAmps

Class A 是較傳統的高線性放大方式。

其基本特點是：

  • 輸出晶體管在整個訊號週期持續導通。
  • 電路設計相對容易理解。
  • 可以達到很低的交越失真。
  • 靜態耗電量高。
  • 發熱量大。
  • 散熱器通常需要很大的體積。

典型效率理論上最高約 25%（電阻負載、單端形式），某些變壓器耦合設計可更高。

適合：

  • 低功率耳機擴大機。
  • 特定高音質單端放大器。
  • 電子電路教學與實驗。

不適合以 USB 5V 供電的高功率喇叭。

2. Class AB：乙類與甲乙類擴大機

High-Power Dual-Channel Amplifier Board (2SA1943/2SC5200 Original Toshiba Tube)

Class AB 是傳統 Hi-Fi 音響非常常見的設計。

主要利用互補功率晶體管放大正、負半週訊號。

優點：

  • 音質成熟。
  • 電路設計資料豐富。
  • 線性度良好。
  • 適合中高功率輸出。
  • 不需要像 Class A 一樣持續消耗大量靜態功率。

缺點：

  • 效率低於 Class D。
  • 散熱器體積較大。
  • 電源供應器通常較重。
  • 偏壓調整與熱補償需要注意。

一般可以用在 20W～200W 的 DIY 家用音響。

3. Class D：數位式開關功率放大器

TPA3255: TPA3255ampBoard-question

最推薦 DIY 入門與現代音響

Class D 是目前非常值得學習的音響放大技術。

它不是單純將類比訊號轉換成數位音訊，而是使用高速開關方式控制功率輸出。

基本原理：

  1. 輸入音訊。
  2. 透過調變電路形成 PWM 或其他開關控制訊號。
  3. 功率 MOSFET 高速切換。
  4. 經過 LC 低通濾波器。
  5. 還原成供應喇叭的音訊。

Principe classe D

主要優點：

  • 效率高，常見設計可達 85%～95% 左右。
  • 體積小。
  • 發熱量低於同功率 Class AB。
  • 容易實現 50W、100W 甚至更高功率。
  • 適合 USB-C PD、DC 電源及開關式電源。

需要注意：Class D 不代表一定是數位音訊。它也可以直接放大類比音訊輸入。

4. Class G / Class H

這兩類設計透過切換或追蹤不同電源電壓，減少功率級的耗散。

特點：

  • 比傳統 Class AB 更有效率。
  • 電路設計較複雜。
  • 電源軌控制及切換設計需要仔細處理。

適合進階音響設計，但如果目標是小型 DIY 音響，我會優先選擇 Class D。

特別注意：為什麼商品標示的瓦數不能直接相信？

假設某個網路商品寫著：

TPA3116D2 100W + 100W

並不代表使用 12V 電源就能輸出 200W。

輸出功率與供電電壓、喇叭阻抗、電路形式及失真率有直接關係。

最基本的功率公式：

\[ P=\frac{V_{\mathrm{RMS}}^2}{R} \]

其中：

  • P：輸出功率。
  • V：喇叭兩端的 RMS 電壓。
  • R：喇叭負載阻抗。

例如，4Ω 喇叭要輸出 50W：

\[ V_{\mathrm{RMS}}=\sqrt{50\times4} =14.14V \]

這表示喇叭兩端必須有約 14.14V RMS 的交流音訊電壓。

因此，必須考慮擴大機的供電電壓和輸出拓撲，不能只看晶片名稱。

2. DAC 數位類比轉換器

ゆっくりラズパイ活用講座

DAC 是 Digital-to-Analog Converter。

它的工作是把數位音訊轉換成類比訊號，再交給前級或功率放大器。

可研究的晶片：

  • PCM5102A：常見 I²S DAC。
  • PCM5242：較高階 DAC，支援數位音訊處理功能。
  • ES9038Q2M：高階 DAC 設計常見選擇。

DAC 選擇時要確認：

  1. 支援的取樣率。
  2. 位元深度。
  3. 訊號輸出電壓。
  4. SNR。
  5. THD+N。
  6. I²S 介面相容性。

不要只看 32-bit、384kHz 等數字。實際音質也取決於電源、時鐘、類比輸出電路及後續放大器。

3. 前級放大器 Preamp

前級主要處理：

  • 音量控制。
  • 輸入切換。
  • 左右聲道平衡。
  • 音調控制。
  • 訊號增益。

常見運算放大器：

晶片 特性
NE5532 經典雙運放
OPA2134 音訊用途常見
OPA1656 低雜訊、高性能 JFET 輸入運放
OPA1612 高性能雙極性輸入運放

XH-A902 NE5532

對 DIY 初學者，建議先使用現成的前級模組，等系統正常運作後，再研究運算放大器的增益、輸入阻抗、負回授及濾波設計。

4. DSP 數位訊號處理

這是現代音響非常值得投入的部分。

DSP（Digital Signal Processing）可以進行：

  • EQ 等化器。
  • 低音增強。
  • 高音調整。
  • 分音器 Crossover。
  • 房間頻率響應修正。
  • 喇叭單體時間校正。
  • 動態範圍控制。
  • 低音喇叭整合。

EVAL-ADAU1701MINIZ Analog Devices Inc.

可以研究：

  • ADAU1701。
  • ADAU1452。
  • ESP32：搭配適當的音訊程式庫及 I²S 周邊。

對於想自己設計兩音路喇叭的人，DSP 特別有用。

例如：

音訊輸入
    │
   DSP
    │
    ├── High Pass Filter ── 高音功放 ── Tweeter
    │
    └── Low Pass Filter ─── 低音功放 ── Woofer

這樣就可以使用兩個獨立功率放大器，分別驅動高音及低音單體，形成主動式分音音響。

七、如何自己設計 Class D 擴大機電路？

如果不滿足於購買現成模組，而希望自己設計 PCB，就要理解功率放大器內部的幾個重要電路。

1. Class D 的基本電路結構

Multilevel Class D Audio Amplifiers for Compact Consumer Applications

主要包含：

  1. 音訊輸入緩衝。
  2. PWM 調變器或整合式控制器。
  3. MOSFET Gate Driver。
  4. 半橋或全橋功率輸出。
  5. LC 濾波器（依架構而定）。
  6. 回授與保護電路。

對於初次設計，我不建議直接自行設計 MOSFET 開關級，因為高頻開關、死區時間、PCB 寄生電感及 EMI 都會大幅增加難度。

更好的做法是：

  • 使用 TI 原廠參考電路。
  • 使用成熟的功放 IC。
  • 自行設計周邊電源、前級及音訊介面。
  • 最後才嘗試重新設計功率級 PCB。

2. 電源去耦電容

這是 Class D 電路穩定性的關鍵。

通常需要：

  • 功率級附近的低 ESR 電解電容。
  • 陶瓷電容。
  • 依資料表要求配置的高頻去耦。
  • 適當的電源走線寬度。

電容必須盡量靠近晶片的電源端，不能將大電容放在遠離功放 IC 的位置，就認為已經完成去耦設計。

3. PCB Layout

4. BTL 輸出注意事項

現代 Class D 很多都採用 BTL（Bridge-Tied Load）。

這表示：

OUT+ ─────── 喇叭 ─────── OUT-

喇叭兩端都由放大器驅動。

因此：

  • OUT- 不是 GND。
  • 不能把 OUT- 接到機殼地。
  • 不能將兩個 BTL 聲道的負端互相連接。
  • 不能直接使用共地式耳機或測試設備接到喇叭輸出端。

這是製作雙聲道 Class D 時非常重要的安全規則。

八、擴大機的保護電路

一套完整的 DIY 音響不應只有放大器，還應考慮保護喇叭及電路本身。

建議加入以下功能：

保護功能 作用 重要程度
Over Current 過電流保護 必要
Over Temperature 過溫保護 必要
Under Voltage 電源電壓不足保護 建議
Over Voltage 電源過壓保護 建議
Short Circuit 喇叭輸出短路保護 必要
DC Protection 異常直流輸出保護 建議
Soft Start 開機緩啟動 建議
Mute Control 開關機靜音 建議

喇叭直流保護

如果功放發生故障，喇叭輸出端可能出現不正常的直流電壓，導致喇叭音圈過熱。

因此，傳統 Class AB 功放常使用 DC 偵測及喇叭繼電器保護。

Class D 則必須注意輸出拓撲：BTL 輸出不能使用一般共地式直流偵測電路直接測量其中一端。應使用適合差動輸出的偵測方式，或採用功放 IC 已提供的故障訊號。

開機爆音問題

常見原因：

  • DAC 啟動時輸出不穩定。
  • Bluetooth 模組開機產生雜訊。
  • 前級電源啟動順序不一致。
  • 功放過早解除 MUTE。

建議使用以下開機順序：

USB / DC 電源接通

        ▼
    電源穩定
        │
        ▼
   DAC / Bluetooth 啟動
        │
        ▼
    前級穩定
        │
        ▼

        ▼

1. 測試輸出功率

假設測試 8Ω 喇叭負載，目標 20W：

使用 1kHz 正弦波，逐漸增加輸入音量，觀察輸出波形。

當輸出波形開始削波（Clipping），就表示接近放大器的輸出極限。

測試時應記錄削波前的 RMS 電壓，並計算實際功率。

2. THD+N 總諧波失真加雜訊

THD+N 是判斷擴大器音質的重要數據。

簡單說：

  • 越低通常越好。
  • 必須同時記錄輸出功率及測試頻率。
  • 不能只比較不同廠商各自挑選的最佳數字。

例如同一台功放：

輸出狀態 THD+N
1W 輸出 0.01%
10W 輸出 0.03%
20W 輸出 0.1%

這只是說明測試表格的示意數據，不代表某一款實際晶片的測量結果。

3. 頻率響應

一般人耳可聽範圍約為 20Hz～20kHz。

測試時可以使用：

  • 20Hz。
  • 50Hz。
  • 100Hz。
  • 500Hz。
  • 1kHz。
  • 5kHz。
  • 10kHz。
  • 20kHz。

觀察輸出是否平坦，以及低頻、高頻是否有異常衰減。

4. 示波器測量 BTL 輸出

這點特別重要。

一般接地式示波器探棒的接地夾不能直接夾在 BTL 功放的 OUT-。

建議使用：

  • 合適的差動探棒。
  • 隔離式測量設備。
  • 專用音訊分析設備。

不可為了測量方便，把示波器接地夾接到 BTL 的喇叭輸出端，否則可能造成短路及設備損壞。
